# SteamGridDB API key

**SteamGridDB** provides community-sourced artwork and game metadata lookup.

## What you need

- A SteamGridDB account
- A personal API key from your profile preferences

## Used for

- **Game** category when SteamGridDB is selected as the source

## Step-by-step

1. Go to [steamgriddb.com](https://www.steamgriddb.com/) and sign in (Steam login or email, depending on their current options).
2. Open your **Profile** → **Preferences** (or go directly to [steamgriddb.com/profile/preferences](https://www.steamgriddb.com/profile/preferences)).
3. Find the **API** or **API key** section.
4. Generate or reveal your API key and copy it.
5. In Backloggy **Settings**, set **Game** source to **SteamGridDB** and paste the key into **SteamGridDB API key**.
6. Tap **Save settings**.

## Tips

- SteamGridDB keys are for personal use; follow their API terms.
- For general game search without custom artwork, **Steam Store** or **RAWG** may be simpler.
