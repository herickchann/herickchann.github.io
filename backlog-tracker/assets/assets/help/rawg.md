# RAWG API key

**RAWG** is a large video game database. Backloggy uses it for game search and **Explore** release-date feeds.

## What you need

- A free RAWG account
- An API key from your RAWG dashboard

## Used for

- **Game** category when RAWG is selected as the source
- **Explore** game discovery (upcoming and recent releases) when a RAWG key is configured

## Step-by-step

1. Go to [rawg.io/apidocs](https://rawg.io/apidocs) and click **Get API Key** (or sign up first).
2. Create a RAWG account if you do not have one.
3. After logging in, open your account / API section. RAWG shows your **API key** on the API docs or dashboard page.
4. Copy the key.
5. In Backloggy, open **Settings**, set **Game** source to **RAWG** if needed, and paste the key into **RAWG API key**.
6. Tap **Save settings**.

## Tips

- The free tier is enough for personal backlog and Explore browsing.
- If you prefer not to use a key, keep **Steam Store** as your game source — search works without a key, but Explore game feeds are limited.
