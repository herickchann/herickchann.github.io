# OMDb API key

**OMDb (Open Movie Database)** provides IMDb-style movie metadata by title or IMDb ID.

## What you need

- A free API key (email verification required)

## Used for

- **Movie** category when OMDb is selected as the source

## Step-by-step

1. Open [omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx).
2. Choose the **FREE** plan (1,000 requests per day) unless you need a higher tier.
3. Enter your email address and complete the form.
4. Check your email and click the verification link from OMDb.
5. Your API key is included in the confirmation email (and on the key page after verification).
6. Copy the key into **Settings → OMDb API key** in Backloggy.
7. Set **Movie** source to **OMDb** if you want to use it for search.
8. Tap **Save settings**.

## Tips

- Free keys are tied to your email; do not share the key publicly.
- OMDb is search-only in Backloggy — **Explore** for movies works best with **TMDB**.
